# Contributing to Pairty

Thanks for your interest in Pairty. Before opening a change, check existing issues and discussions.

## Proposing changes

1. Open an issue with the problem and proposed approach.
2. Use a focused branch and a descriptive commit message.
3. Open a pull request explaining what changed, why it matters, and how it was verified.
4. Never include secrets, personal data, or private customer information.

## Review

Maintainers review contributions before merging. Please keep discussions respectful and constructive.
